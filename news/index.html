Release write-ups & development notes

What changed and why, written by a person rather than generated from a changelog. There is an RSS feed if you would like these the old-fashioned way.

  • 15 August 2026

    Copperline 0.16.0: one-command WHDLoad, a game library, and a new Amiga game built on Copperline

    A WHDLoad-installed game boots straight from its archive, the launcher grows a browsable game library with OpenRetro cover art, --run warp-boots freshly built Amiga executables for developers, storage gains a lide.device-compatible IDE board with ATAPI CD-ROM, OFS directory mounts that boot Kickstart 1.3 and a Create Image workshop - and a studio building a new commercial Amiga game on Copperline drove fixes from Agnus pointer semantics to floating-bus reads.

    read the write-up >
  • 8 August 2026

    Copperline 0.15.0: an MT-32, your real hard disks, and sockets with nothing to install

    An emulated Roland MT-32 - front panel and all - on the MIDI port, the host's real hard disks handed to the machine RDB and all, a HostSocket board giving guest applications BSD sockets with no TCP/IP stack to install, the physical floppy path rebuilt pure-Rust on FluxBridge, native IPF and CHD images, a redesigned menu tree, an authentic 1084 bezel, integer scaling and a performance overlay, and a browser build with a screen keyboard and real headroom on phones.

    read the write-up >
  • 1 August 2026

    Copperline 0.14.0: real drives, real networks, and a 1084 on your desk

    Real 3.5" floppy drives on the emulated bus through DrawBridge, Greaseweazle and SupercardPro, the A2065 bridged onto the real LAN, Picasso II / II+ RTG for the 24-bit machines, CRT shaders, screen tints and a 1084-style bezel, rewind and quick-save slots, autofire and input remapping, an experimental JIT CPU mode, and a WinUAE-inspired debugging suite.

    read the write-up >
  • 25 July 2026

    Copperline 0.13.0: RTG, Ethernet and a Linux login prompt

    RTG graphics through the Z3660 Zorro III board, Ramsey motherboard and CPU-slot accelerator RAM for the big boxes, an Ethernet backend that needs no privileges or setup, a telnet BBS dialled over emulated serial, configurable floppy speed, and enough 68040 MMU and 31 kHz display work to boot Debian Linux/m68k to a login prompt.

    read the write-up >
  • 24 July 2026

    Copperline moves to its own GitHub organisation

    The repositories have moved from my personal LinuxJedi account to a new GitHub organisation, CopperlineHQ, because Copperline is becoming a community bigger than just me. Repository names are unchanged, the old URLs keep redirecting for the foreseeable future, and a Discord server for development discussion is on the way.

    read the note >
  • 18 July 2026

    Copperline 0.12.0: the browser build and the big boxes

    The whole emulator compiled to WebAssembly and running client-side at copperline.dev/try, A3000 / A4000 profiles booting from their onboard SCSI and IDE, host-directory mounts gone writable, a JSON-RPC control protocol for scripted live sessions, SCSI CD-ROM drives with CD audio, and any controller in either game port.

    read the write-up >
  • 12 July 2026

    Copperline 0.11.0: boot from a host directory

    Host directories mounted - and booted - as live AmigaDOS volumes, the blitter's BLTPRI bus fence, a 68000 microcode write-ordering pass, sprite serialization measured against other emulators and real hardware, and a 6x cut in worst-case frame times on slower hosts.

    read the write-up >
  • 7 July 2026

    Copperline 0.10.0: the 68060, the MMUs and a much bigger debugger

    The 68060 joins the CPU line-up, the 68030 / 68040 gain real MMU and cache behaviour, the debugger grows a command console plus Video, Audio and IO Map tabs, and the A4091 SCSI board, MIDI and TCP serial bridges and zipped floppies arrive - much of it contributed.

    read the write-up >
  • 29 June 2026

    Copperline 0.9.0: the FPU deep-dive

    An 80-bit 68881/68882 accuracy pass with pure-Rust softfloat, explicit joystick input selection, save states that restore without the original ROM, and the usual round of CIA, Paula, keyboard and display-timing fixes.

    read the write-up >
  • 27 June 2026

    Copperline 0.8.0

    The no-config machine launcher, external WASM Zorro board plugins, A2065 Ethernet with a loopback backend, and a long list of sprite, Denise and bitplane timing fixes.

    release notes on GitHub >

    Copperline 0.7.0

    Expanded machine profiles (A500 Rev 6A, A500OCS, A500+, A1000), conditional and counted breakpoints, warp-speed frame skipping, and the first macOS .dmg release builds.
