News and releases

Release notes and development updates for Copperline. Follow new posts with the RSS feed.

  • 26 September 2026

    Copperline 1.0.0-rc.1: the first release candidate for 1.0

    The first release candidate for Copperline 1.0 adds three- and four-player netplay on the desktop, debugger watches on device registers, a timed CD32 drive trace and a refreshed AROS ROM. Please test it and report anything that worked in 0.21.0 but does not now.

    Read release notes
  • 19 September 2026

    Copperline 0.21.0: spectators, four controllers and desktop fixes

    Invite up to eight spectators to a netplay game, use four local controllers on the desktop and in RetroArch, and pick up display and file-picker fixes. Clipboard sharing and the CD32 FMV cartridge are now opt-in.

    Read release notes
  • 12 September 2026

    Copperline 0.20.0: Netplay, a new debugging workspace, and RetroArch

    Two-player netplay, a shared debugging workspace and a RetroArch core, plus save-state thumbnails, GIF clips and Paula audio improvements.

    Read release notes
  • 6 September 2026

    Copperline 0.19.0: Amiga debugging from VS Code, Bartman's profiler on Copperline, and two open ROMs

    Source-level debugging in VS Code, support for Bartman's visual profiler, and open-source CD32 FMV and A2091 ROMs, plus timing fixes checked against real hardware.

    Read release notes
  • 29 August 2026

    Copperline 0.18.0: The CD32 FMV module, calibrated drive timing, a modem on Paula, and import-uae

    CD32 FMV emulation, CD drive timing measured on real hardware, and a Hayes-compatible serial modem. copperline-import-uae converts configurations from other emulators.

    Read release notes
  • 22 August 2026

    Copperline 0.17.0: Coppersynth, two sound boards, and CD32 discs that boot without a Kickstart

    Coppersynth General MIDI, the Toccata and MHI sound boards, and CD32 discs that boot on AROS. Gamepads can now drive the whole interface.

    Read release notes
  • 15 August 2026

    Copperline 0.16.0: one-command WHDLoad, a game library, and a new Amiga game built on Copperline

    Launch WHDLoad archives directly, browse a game library, and run freshly built Amiga programs from the command line.

    Read release notes
  • 8 August 2026

    Copperline 0.15.0: an MT-32, your real hard disks, and sockets with nothing to install

    Roland MT-32 emulation, access to the host's physical hard disks, and guest sockets without a TCP/IP stack. Physical floppy support moves to FluxBridge.

    Read release notes
  • 1 August 2026

    Copperline 0.14.0: real drives, real networks, and a 1084 on your desk

    Physical floppy drives, bridged Ethernet and Picasso II RTG graphics, plus CRT shaders, rewind, input remapping and an experimental JIT.

    Read release notes
  • 25 July 2026

    Copperline 0.13.0: RTG, Ethernet and a Linux login prompt

    Z3660 RTG graphics and user-mode NAT networking, plus the MMU and display work needed to boot Linux/m68k.

    Read release notes
  • 24 July 2026

    Copperline moves to its own GitHub organization

    The repositories move from LinuxJedi to CopperlineHQ as the project's community grows. Existing repository links keep redirecting.

    Read the announcement
  • 18 July 2026

    Copperline 0.12.0: the browser build and the big boxes

    Copperline comes to the browser. On the desktop, A3000 and A4000 profiles, writable host directories and a JSON-RPC control protocol arrive.

    Read release notes
  • 12 July 2026

    Copperline 0.11.0: boot from a host directory

    Boot from a host directory, with blitter, CPU and sprite timing fixes and lower frame times on slower hosts.

    Read release notes
  • 7 July 2026

    Copperline 0.10.0: the 68060, the MMUs and a much bigger debugger

    68060 support, 68030/040 MMU and cache modelling, and new debugger inspectors, plus A4091 SCSI and MIDI and TCP serial bridges.

    Read release notes
  • 29 June 2026

    Copperline 0.9.0: the FPU deep-dive

    An 80-bit FPU accuracy pass, explicit joystick input selection, and save states that restore without the original ROM file.

    Read release notes
  • 27 June 2026

    Copperline 0.8.0

    The no-config machine launcher, external WASM Zorro board plugins, A2065 Ethernet with a loopback backend, and a long list of sprite, Denise and bitplane timing fixes.

    Release notes on GitHub
  • 25 June 2026

    Copperline 0.7.0

    Expanded machine profiles (A500 Rev 6A, A500OCS, A500+, A1000), conditional and counted breakpoints, warp-speed frame skipping, and the first macOS .dmg release builds.
