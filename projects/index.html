Projects using Copperline

Community projects and tools built with or around Copperline. If you have created something using Copperline and would like it listed here, please open an issue on the site repository.

  • by Retro32

    Retro32 BBS

    Retro gaming store Retro32 uses the WebAssembly build of Copperline as a web-based client for their dial-up BBS. Utilizing the emulator's serial-over-WebSocket bridging, visitors can connect directly to the BBS from an emulated Amiga terminal right in the browser without any local setup.

  • by Simon Dick

    copperline-docker

    A self-hosted Docker container for running the WebAssembly build of Copperline via nginx. Pre-built multi-arch images (amd64 and arm64) are available on GitHub Container Registry, with support for mounting host directories containing custom Kickstart ROMs and disk images.
