// get started

Download and run

Copperline includes AROS, an open-source Kickstart replacement, so it boots without a ROM of your own. Bring your own disk images; some software needs an original Kickstart ROM. Check compatibility.

Download for macOS

For Apple Silicon and Intel Macs. Open the DMG and copy Copperline.app to Applications.

The app is ad-hoc signed rather than notarized, so macOS may block the first launch. Allow it in System Settings → Privacy & Security → Open Anyway.

Install with Homebrew 
brew tap CopperlineHQ/copperline https://github.com/CopperlineHQ/Copperline
brew install copperline
Download for Linux

AppImage for x86-64. Make it executable, then launch it:

chmod +x Copperline-0.21.0-x86_64.AppImage
./Copperline-0.21.0-x86_64.AppImage

A Vulkan driver is required. See the Linux setup guide.

Download for Windows x64 Windows ARM64

Extract the whole ZIP, then open copperline.exe. Keep the folders beside it: they hold the bundled ROMs and WHDLoad support files.

  1. Install Copperline

    Pick the download for your system, or open the browser version.

  2. Choose your Amiga

    The launcher starts with an A500 running AROS. Choose another machine or your own Kickstart ROM, then start it. Configuration guide.

  3. Load your software

    On the desktop, drag a disk image onto the window or insert one from the status bar. WHDLoad archives can be launched directly.

Upgrading to 0.21? Clipboard sharing and the CD32 FMV cartridge are now opt-in. Recreate RetroArch save states after updating the core. Read the upgrade notes.

Build from source or try the development branch

Building from source needs Rust 1.95 or newer and the dependencies for your platform.

git clone https://github.com/CopperlineHQ/Copperline.git
cd Copperline
cargo build --release
./target/release/copperline

With the Homebrew tap installed, brew install --HEAD copperline builds the latest development version.

Make a bug repeatable

Schedule inputs and captures from the command line, record a session to a .clscript file, or drive a running machine through the JSON-RPC control protocol.

Headless run: press Space at 4 s and take a screenshot at 12 s of emulated time
copperline --factory --model A500 --insert-disk-after 0 df0 game.adf \
  --noaudio --press-after 4 SPACE --screenshot-after 12 shot.png

A run repeats exactly when the configuration, media, clock seeds and inputs are the same. Live host files, networks and physical devices can make runs differ. Determinism and the host boundary.

// compatibility · 0.21.0

Compatibility and limitations

Games, demos and Workbench run on OCS, ECS and AGA machines, but not everything works yet. Compatibility depends on the software and the configuration, and accuracy improves with each release.

ROMs and software
AROS is included, so you can start straight away. Some games and Workbench installations need an original Kickstart ROM. ROM and setup guide.
Netplay
Two desktops or two browsers running the same Copperline build can play together, with up to eight spectators of the same kind. A desktop cannot connect to a browser, and mixing operating systems or browser engines has not been verified yet. Netplay requirements.
Experimental JIT
The optional JIT for 68020 and later CPUs changes CPU timing and is off by default. Leave it off when accurate instruction timing matters. CPU settings.
Physical floppy drives
Real drives work through a Greaseweazle controller and FluxBridge; other flux controllers are not supported. A save state cannot rewind a physical disk. Supported hardware and limitations.
Disk formats
Floppy images must be double-density Amiga disks. High-density (1.76 MB) Amiga images and sector-based PC/CrossDOS images are not supported. Supported image formats.
Keyboard layouts
Host keys map to Amiga keys by physical position, not by the host's keyboard layout, and there is no layout setting yet.

CPU behaviour is checked against the SingleStepTests 68000 corpus and WinUAE's cputest sets, chipset behaviour against vAmigaTS and Copperline's own probe disks, and timing against measurements on real Amigas. The documentation has the details.

Found a problem? Check the existing issues or report it with the version, the machine configuration and the steps to reproduce it. An input recording helps.

// questions

A few things to know

Do I need a Kickstart ROM?

No. Copperline boots its included AROS ROM straight away. Some software needs an original Kickstart ROM; if you have one, select it in the launcher. Read the setup guide.

How does Copperline compare with other Amiga emulators?

WinUAE, FS-UAE and vAmiga have many years of compatibility work behind them, and Copperline is much younger. It concentrates on reverse debugging, chip-bus analysis, scripting and repeatable tests. The browser build and netplay also make it easy to try a configuration or play together.

Is the macOS build notarized?

Not yet. The downloads are ad-hoc signed, so macOS asks you to approve the first launch in Privacy & Security. Installing with Homebrew builds Copperline from source on your Mac instead, so there is nothing to approve.

How was Copperline developed?

I work from hardware documentation, real Amigas and test disks. AI coding assistants help with implementation, tests and debugging, and changes are checked with hardware tests and regression runs.

Where does the name come from?

The Copper is the Amiga's display coprocessor. It runs alongside the CPU and writes chipset registers in step with the video beam, which is how raster effects such as colour bars are drawn. Copperline is named after it.
