Start with Boot AROS, or use Insert DF0 to load a floppy image. Controls has machine settings and an option to load your own Kickstart ROM.

Click the screen to capture the mouse; press Esc to release it. Joystick enables keyboard or touch game controls, and Keyboard opens the on-screen Amiga keys.

Play together with Netplay

Connect two browsers using the same Copperline build, with up to eight more watching. The host shares ROMs, disks and settings; connecting starts a fresh machine and replaces the running game. Until player 2 arrives, the host can keep playing and change disks.

  1. Open Netplay. For Lemmings or another two-mouse game, choose Advanced → Controllers → Two mice before hosting.
  2. Choose Host game and share the invitation privately. The other player opens it and chooses Join game. Files transfer automatically; the guest needs no local copies.
  3. To let others watch, share the separate Spectator invitation or its QR code, shown under your own. Up to eight spectators open it and choose Watch game. They can join at any point, replay the game from its start to catch up, and never send input.
  4. For another disk, the host chooses DF0 or DF1 in Netplay and uses Swap disk. Both machines pause for the transfer, then resume together.

The host controls port 1 and the guest controls port 2. Switch Joystick off to type on the shared Amiga keyboard. Keep both pages open. Disconnecting ends the game and discards the session’s disk writes; a spectator leaving changes nothing for the players.

Player invitations expire after 15 minutes; an established game can continue, and its spectator invitation stays valid while the host is playing. Transfers are encrypted, and the guest’s saved ROM and local setup are preserved. Use Copy diagnostics if a connection fails. Full Netplay guide and connection options.

Save states and disk images

Quick save keeps a snapshot in this browser. Save state downloads a .clstate file that desktop builds of the same release can open. Saved states manages named snapshots.

Save states from 0.19 and earlier cannot be loaded. Disk images and ordinary in-game saves are unaffected.

Floppy formats include ADF, ADZ, DMS, IPF and SCP. Under Controls, DF0 from URL loads an image from a server that allows cross-origin requests. Browser storage and media guide.

Machine, display and input settings

The default is an A500 with 512 KB Chip RAM, 512 KB Slow RAM and AROS. Under Controls → Machine, choose an A500 or A1200 and PAL or NTSC video.

Display has CRT effects, scaling, overscan and bezels. Joystick uses the arrow keys and Right Ctrl/Alt for port 2 during local play; phones also have touch controls. Hold Esc to exit fullscreen.

The page’s light/dark switch changes the website, leaving the emulated picture and monitor settings as you chose them.

Emulation runs on your device. The included AROS ROM uses the AROS Public License; original Commodore ROMs are not included. Report a bug.
